# FitFlow Redesign

## Overview

FitFlow is a fitness application redesign developed as part of the IT3060 – Human Computer Interaction laboratory exercise.

The project focuses on designing a modern fitness platform with support for personalized workout planning, social interaction, nutrition tracking, and AI-powered features.

## Project Structure

```text
fitflow-redesign/
│
├── frontend/       # Frontend application
├── backend/        # Backend services and APIs
├── ai-service/     # AI/ML-related services
├── docs/           # Project documentation
└── .github/
    └── workflows/  # GitHub Actions workflows
```

## Main Features

* Personalized workout plans
* Workout and fitness tracking
* Nutrition tracking
* Social sharing
* AI-assisted fitness features
* User authentication and authorization
* Real-time application features
